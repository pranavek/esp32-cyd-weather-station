ESP32 CYD Weather Station

One-click installer. Flashes firmware + filesystem to the Cheap Yellow Display, then walks you through WiFi + OpenWeather setup from your phone.

Requires Chrome, Edge, or Opera on desktop. Safari and Firefox don't support Web Serial.

How it works

  1. Plug the CYD into your computer via USB.
  2. Click Connect above and pick the serial port (Silicon Labs CP210x / CH340 on most CYDs).
  3. Click Install. Takes about a minute — bootloader, partitions, app, and the LittleFS image (icons + fonts) all flash in one shot.
  4. When the device reboots it shows cyd-weather-setup as its WiFi network. Connect from your phone or laptop.
  5. A captive portal opens automatically (most phones). Fill in:
    • your home WiFi
    • your OpenWeatherMap API key (free from openweathermap.org)
    • latitude / longitude
    • units (metric / imperial)
    • timezone (incl. IST for India)
    • sleep hours (when the screen goes dark)
  6. Save. The device reboots into normal operation and starts drawing weather.

Reconfiguring later

To re-enter the captive portal (e.g. moved to a new WiFi network), erase the NVS partition. Easiest path: re-flash from this page with "erase device" ticked.

Prefer to build from source?

The classic PlatformIO install path still works — edit src/All_Settings.h with your values and run pio run -t uploadfs && pio run -t upload. Source on GitHub.
